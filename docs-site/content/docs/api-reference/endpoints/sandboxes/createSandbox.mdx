      - content: >
          Creates a sandbox on a connected node and returns it as `active`.


          Send `multipart/form-data`. Both parts are optional:


          - `archive`: a gzipped tar of your project. If it contains a
          `cider.yaml` at its root
            (or one directory down, as `cider open` uploads it), Cider applies `setup`, `start`,
            and `resources.min_storage`.
          - `node_id`: pin the sandbox to one node.


          Without an archive you get an empty sandbox with the base image.
